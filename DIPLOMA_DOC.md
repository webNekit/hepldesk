# Документация к дипломному проекту: Корпоративный портал и Helpdesk

## 1. Контекст проекта
**Заказчик:** ГКУ ВО "МАЦ" (Комитет сельского хозяйства Волгоградской области).
**Цель:** Автоматизация процессов технической поддержки сотрудников и создание единого информационного пространства для внутренней работы ведомства.

---

## 2. Технологический стек
Проект реализован на современном стеке технологий, обеспечивающем высокую производительность и реактивность интерфейса без перезагрузки страниц:
- **Backend:** Laravel 13 (PHP 8.4).
- **Frontend:** Livewire (реактивные компоненты) + Alpine.js.
- **Стилизация:** Tailwind CSS v4 (использование современных CSS-переменных и @theme).
- **База данных:** SQLite (для демонстрации) / MySQL.
- **Роли и права:** Spatie Laravel-Permission.
- **Логирование:** Spatie Activitylog (Audit Log).
- **Таблицы:** PowerGrid (фильтрация, поиск, экспорт).

---

## 3. Требования преподавателя (Техническое задание)
В соответствии с требованиями научного руководителя, в проекте реализовано:
1. **Чистая ручная разработка:** Полный отказ от конструкторов админ-панелей (Filament, Nova, Orchid). Весь функционал написан вручную на Livewire.
2. **Модуль "Телефонный справочник":** Таблица сотрудников с быстрым поиском по ФИО, отделу и кабинету.
3. **Модуль "Умная Helpdesk-система":**
   - Выбор категории проблемы.
   - **Реактивные подсказки:** Автоматический показ инструкции по решению проблемы при выборе категории (самообслуживание).
   - **Авто-распределение:** Автоматическое назначение заявки на ответственного специалиста ИТ-отдела в зависимости от категории.
4. **Кабинет ИТ-специалиста:** Панель управления заявками, чат с пользователем и управление статусами.

---

## 4. Реализованный функционал (Модули)

### 4.1. Система заявок (Helpdesk)
- **Создание заявки:** Умная форма с валидацией, выбором приоритета и привязкой оборудования.
- **SLA (Сроки исполнения):** Автоматический расчет крайнего срока (Due Date) в зависимости от приоритета (2ч для высокого, 24ч для среднего, 48ч для низкого).
- **Публичный трекинг:** Генерация уникальной ссылки (`UUID`) для каждой заявки. Клиент может отслеживать статус без авторизации.
- **Оценка качества (CSAT):** После решения проблемы клиент может оставить оценку (1-5 звезд) и отзыв.

### 4.2. Инвентаризация и Активы (Asset Management)
- Полный учет ИТ-оборудования (ПК, принтеры, сетевые устройства).
- Привязка конкретного устройства к заявке для быстрого поиска истории поломок.
- Отслеживание серийных номеров и состояния (В работе/Ремонт).

### 4.3. База знаний (Knowledge Base)
- Раздел с инструкциями и регламентами.
- Поиск по материалам и фильтрация по категориям.
- Поддержка прикрепленных PDF-файлов с руководствами.

### 4.4. Аналитика и Дашборд
- Визуализация статистики: количество заявок, среднее время решения, уровень удовлетворенности пользователей.
- Рейтинг эффективности техников.
- Распределение нагрузки по отделам.

### 4.5. Уведомления и Коммуникация
- **Система "Колокольчик":** Мгновенные уведомления о новых комментариях и смене статусов.
- **Журнал аудита:** Полная история действий по каждой заявке (кто, когда и что изменил).
- **Чат:** Возможность прямого общения между техником и пользователем внутри заявки.

---

## 5. Ролевая модель
1. **Сотрудник (Employee):** Создает заявки, пользуется справочником и базой знаний.
2. **ИТ-специалист (IT Support):** Решает заявки, управляет оборудованием, общается с клиентами.
3. **Администратор (Admin):** Полный доступ к настройкам системы, управлению пользователями и аналитике.

---

## 6. Запуск проекта для демонстрации
1. Склонировать репозиторий.
2. Выполнить `composer install` и `npm install`.
3. Настроить `.env` (БД SQLite).
4. Запустить миграции с сидами: `php artisan migrate:fresh --seed`.
5. Запустить сервер: `php artisan serve` и `npm run dev`.
